# Project Solo (repository root)

The game lives in `source/`. **Read `source/CLAUDE.md` first**; it has the commands, the rules and the reading order. Then `source/docs/HANDOVER.md`.

Three things to know before anything else:
- **Commit locally only. Do not push, open PRs or merge** until the owner asks for "the big push".
- **`Project Solo.app` must stay the first item in this folder.** Do not add files here that sort before it (this file is in a hidden folder for that reason).
- **Never `git add -A` or `git add .`**: hundreds of untracked Finder duplicates ("name 2.gd") sit in the working folder. Add files by name.
